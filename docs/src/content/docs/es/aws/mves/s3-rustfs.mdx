Esta guía te muestra cómo trabajar con **AWS S3** usando **RustFS** como emulador local. Este lab demuestra un pipeline de datos usando **Boto3**, **PyArrow** y **Delta Lake** (delta-rs).

## Prerrequisitos

- [Docker](https://www.docker.com/get-started) instalado y en ejecución.
- [Dev Containers extension](vscode:extension/ms-vscode-remote.remote-containers) instalada (opcional).

## Cómo ejecutar

<Steps>
   1. **Configurar el entorno**:
      <Tabs>
         <TabItem label="Dev Container (recomendado)">
            Abre **VS Code** en la carpeta del proyecto y ejecuta este comando en la **Paleta de Comandos**:
            ```bash
            > Dev Containers: Reopen in Container
            ```
         </TabItem>
         <TabItem label="Manual">
            1. **Inicia la infraestructura**: Lanza los contenedores necesarios.
               ```bash
               docker compose up -d
               ```
            2. **Ejecuta el script** de configuración para instalar herramientas y dependencias.
               ```bash
               scripts/setup.sh
               ```
         </TabItem>
      </Tabs>

   2. **Ejecutar el ejemplo**:
      ```bash
      python main.py
      ```
</Steps>

## Cómo depurar

1. **main.py**:
   - **Abre**: Abre `main.py`.
   - **Breakpoints**: Coloca breakpoints en el código.
   - **Ejecuta**: Pulsa `F5` para iniciar la depuración.

2. **Tests**:
   - **Abre**: Abre un fichero de test (p. ej., `tests/components/test_s3_boto.py`).
   - **Breakpoints**: Coloca breakpoints en el código del test.
   - **Ejecuta**: Usa la pestaña **Testing** de VS Code y haz clic en el icono **Debug Test** junto al test que quieras depurar.

## Cómo testear

- **Individualmente**: Ejecuta los tests individualmente desde la pestaña **Testing** de VS Code.
- **Todos los tests**: Ejecuta el script automatizado:
  ```bash
  scripts/run_tests.sh
  ```

## Validar resultados

<Tabs>
   <TabItem label="RustFS Console">
      - **Abre** en tu navegador:
        ```bash
        http://localhost:9001/rustfs/console/
        ```
      - **Inicia sesión**: Usa el `S3_ACCESS_KEY` y el `S3_SECRET_KEY` definidos en tu `.env`.
      - **Verifica**: Revisa los buckets `bronze` y `silver` para ver los archivos subidos.
   </TabItem>
   <TabItem label="AWS CLI">

## Limpieza

```bash
docker compose down -v
```

## Solución de problemas

| Problema | Solución |
|----------|----------|
| API de RustFS no lista | Asegúrate de que el servicio `rustfs` está en ejecución y espera unos segundos a que la API se inicialice. Revisa los logs con `docker compose logs rustfs`. |
| Puerto 9000 o 9001 en uso | El lab de S3 (MinIO) usa los mismos puertos. Deténlo antes de arrancar este, o cambia el mapeo en `docker-compose.yml`. |
