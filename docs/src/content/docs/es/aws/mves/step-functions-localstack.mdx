Esta guía te muestra cómo trabajar con **AWS Step Functions** localmente usando **LocalStack**, **Python** y el **AWS Toolkit para VS Code**. Este lab demuestra un flujo de incorporación de usuarios con ejecución paralela de Lambda y creación de usuarios IAM.

## Prerrequisitos

- [Docker](https://www.docker.com/get-started) instalado y en ejecución.
- [Dev Containers extension](vscode:extension/ms-vscode-remote.remote-containers) instalada (opcional).
- [AWS Toolkit para VS Code](https://marketplace.visualstudio.com/items?itemName=amazonwebservices.aws-toolkit-vscode) instalado (opcional, incluido en el Dev Container).

## Cómo ejecutar

<Steps>

1. **Configurar el entorno**:
   <Tabs>
      <TabItem label="Dev Container (recomendado)">
         Abre **VS Code** en la carpeta del proyecto y ejecuta este comando en la **Paleta de Comandos**:
         ```bash
         > Dev Containers: Reopen in Container
         ```
      </TabItem>
      <TabItem label="Manual">
         1. **Inicia la infraestructura**: Levanta el contenedor de LocalStack.
            ```bash
            docker compose up -d
            ```
         2. **Ejecuta el script de setup** para instalar herramientas y dependencias, configurar el perfil `localstack` del AWS CLI y empaquetar los artefactos de las Lambdas en `dist/`.
            ```bash
            scripts/setup.sh
            ```
      </TabItem>
   </Tabs>

2. **Desplegar los recursos**: Crea la tabla de DynamoDB, las Lambdas y la Step Function con el método por defecto.
   ```bash
   scripts/deploy/boto3/deploy.sh
   ```

3. **Ejecutar el ejemplo**:
   ```bash
   scripts/run_main.sh
   ```

</Steps>

:::note[Reconstruir los artefactos]
El despliegue siempre consume los zips de `dist/`. Después de cambiar una Lambda, reconstrúyelos antes de volver a desplegar: `scripts/build.sh`
:::

## Cómo depurar

1. **Script de Python (main.py)**:
   - **Abre**: `main.py` en VS Code.
   - **Selecciona**: La configuración **Python: main.py** en la pestaña **Run and Debug**.
   - **Ejecuta**: Pulsa `F5` y recorre paso a paso la ejecución del flujo.
2. **Despliegue (deploy/boto3/deploy.py)**:
   - **Selecciona**: La configuración **Python: deploy (boto3)** para depurar la creación de la tabla, las Lambdas y la Step Function.
3. **Tests**:
   - **Abre**: La pestaña **Testing** de VS Code y depura cualquier test con puntos de ruptura.

## Cómo testear

- **Todos los tests**: Ejecuta el script automatizado: `scripts/run_tests.sh`
- **Individualmente**: Usa la pestaña **Testing** de VS Code para ejecutar o depurar tests concretos.

## Validar resultados

<Tabs>
   <TabItem label="AWS CLI">
      Todos los comandos usan el perfil `localstack` creado durante el setup, que apunta a `LOCALSTACK_ENDPOINT` del fichero `.env`.

      - **Verifica la creación del usuario IAM**:
        ```bash
        aws iam list-users --profile localstack
        ```
      - **Verifica los logs de DynamoDB**: el nombre de la tabla viene de `DYNAMODB_TABLE` en el fichero `.env`.
        ```bash
        aws dynamodb scan --table-name UserLogs --profile localstack
        ```
      - **Verifica las funciones Lambda**: sus nombres vienen de `LOG_USER_FUNCTION` y `VALIDATE_EMAIL_FUNCTION` en el fichero `.env`.
        ```bash
        aws lambda list-functions --profile localstack
        ```
      - **Verifica la máquina de estados**: su nombre viene de `STEP_FUNCTION_NAME` en el fichero `.env`.
        ```bash
        aws stepfunctions list-state-machines --profile localstack
        ```
   </TabItem>
   <TabItem label="AWS Toolkit">
      1. **Abre la Paleta de Comandos**: Pulsa `F1` o `Ctrl+Shift+P`.
      2. **Conecta**: Escribe y selecciona **AWS: Connect to AWS**.
      3. **Selecciona el perfil**: Selecciona el perfil `localstack`.
      4. **Visualiza el grafo**: Abre `step_function.asl.json` y haz clic en el icono **Visual Graph** (arriba a la derecha).
      5. **Ejecuta**: En el **AWS Explorer**, haz clic derecho en la máquina de estados y selecciona **Start Execution**.
   </TabItem>
</Tabs>

   </TabItem>
   <TabItem label="Boto3">

   </TabItem>
</Tabs>

Para eliminar también todos los contenedores y volúmenes:

```bash
docker compose down -v
```

## Solución de problemas

| Problema | Solución |
|----------|----------|
| Conexión rechazada | Asegúrate de que LocalStack está en ejecución: `docker ps` |
| El flujo termina con estado `FAILED` | La Lambda `ValidateEmail` rechaza emails con formato inválido. Revisa los detalles de la ejecución que imprime `main.py`. |
| `ResourceNotFoundException` con `dist/*.zip` | Faltan los artefactos. Constrúyelos: `scripts/build.sh` |
| Error de recurso ya existente al desplegar | Has cambiado de método sin limpiar. Ejecuta el script **destroy** del método anterior. |
