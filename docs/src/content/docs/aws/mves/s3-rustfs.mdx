This guide shows you how to work with **AWS S3** using **RustFS** as a local emulator. This lab demonstrates a data pipeline using **Boto3**, **PyArrow**, and **Delta Lake** (delta-rs).

## Prerequisites

- [Docker](https://www.docker.com/get-started) installed and running.
- [Dev Containers extension](vscode:extension/ms-vscode-remote.remote-containers) installed (optional).

## How to execute

<Steps>
   1. **Setup Environment**:
      <Tabs>
         <TabItem label="Dev Container (recommended)">
            Open **VS Code** in the project folder and execute this command in the **Command Palette**:
            ```bash
            > Dev Containers: Reopen in Container
            ```
         </TabItem>
         <TabItem label="Manually">
            1. **Start Infrastructure**: Launch the required containers.
               ```bash
               docker compose up -d
               ```
            2. **Run the setup** script to install tools and dependencies.
               ```bash
               scripts/setup.sh
               ```
         </TabItem>
      </Tabs>

   2. **Run the Example**:
      ```bash
      python main.py
      ```
</Steps>

## How to debug

1. **main.py**:
   - **Open**: Open `main.py`.
   - **Breakpoints**: Set breakpoints in the code.
   - **Run**: Press `F5` to start debugging.

2. **Tests**:
   - **Open**: Open a test file (e.g., `tests/components/test_s3_boto.py`).
   - **Breakpoints**: Set breakpoints in the test code.
   - **Run**: Use the VS Code **Testing** tab and click the **Debug Test** icon next to the test you want to debug.

## How to test

- **Individually**: Run tests individually from the VS Code **Testing** tab.
- **All tests**: Run the automated script:
  ```bash
  scripts/run_tests.sh
  ```

## Validate results

<Tabs>
   <TabItem label="RustFS Console">
      - **Open** in your browser:
        ```bash
        http://localhost:9001/rustfs/console/
        ```
      - **Log in**: Use the `S3_ACCESS_KEY` and `S3_SECRET_KEY` defined in your `.env`.
      - **Verify**: Check the `bronze` and `silver` buckets to see the uploaded files.
   </TabItem>
   <TabItem label="AWS CLI">
      - **Check Buckets**: Verify that `bronze` and `silver` buckets were created.
        <Tabs syncKey="cli-runner">
           <TabItem label="Global">
              ```bash
              aws s3 ls --profile rustfs
              ```
           </TabItem>
           <TabItem label="Mise">
              ```bash
              mise exec -- aws s3 ls --profile rustfs
              ```
           </TabItem>
        </Tabs>
      - **Check Content**: Verify the files in the silver bucket.
        <Tabs syncKey="cli-runner">
           <TabItem label="Global">
              ```bash
              aws s3 ls s3://silver --recursive --profile rustfs
              ```
           </TabItem>
           <TabItem label="Mise">
              ```bash
              mise exec -- aws s3 ls s3://silver --recursive --profile rustfs
              ```
           </TabItem>
        </Tabs>
   </TabItem>
</Tabs>

## Clean Up

```bash
docker compose down -v
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| RustFS API not ready | Ensure the `rustfs` service is running and wait a few seconds for the API to initialize. Check logs with `docker compose logs rustfs`. |
| Port 9000 or 9001 in use | The S3 (MinIO) lab uses the same ports. Stop it before starting this one, or change the mapping in `docker-compose.yml`. |
